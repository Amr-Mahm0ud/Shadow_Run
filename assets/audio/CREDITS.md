## Sound Effects (SHADOW//RUN Audio Pack mappings)
| File | Trigger |
|------|---------|
| `melee_swing_air.wav` | Melee misses |
| `melee_hit_enemy.wav` | Melee connects / light hits |
| `player_damaged.wav` | Player takes damage |
| `jump.wav` / `slide.wav` / `dodge.wav` | Movement gestures |
| `ranged_fire.wav` / `reload.wav` | Ranged fire & reload cycle |
| `special_ability.wav` / `ultimate.wav` | Ability / ultimate |
| `enemy_spawn.wav` / `enemy_death.wav` | Enemy enter / kill |
| `boss_warning.wav` | Boss telegraph |
| `footstep.wav` | Periodic run footsteps |
| `pickup_reward.wav` | Coins/XP/reward pickup |
| `ui_click.wav` / `pause.wav` / `resume.wav` | UI |

Drop replacement WAV/MP3 files with these exact names into `assets/audio/` to swap the pack without code changes.
